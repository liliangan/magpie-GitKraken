# GitKraken Stash Message Generation

[中文](README.md)

## Purpose

Choose a model specifically for GitKraken's stash message generation feature. This plugin updates only the model for stash message generation; it does not configure the gateway connection.

## Usage

1. Enable “GitKraken 提交消息生成（Magpie 网关）” first and complete the GitKraken Magpie gateway connection.
2. On Magpie's Agents page, enable “GitKraken 贮藏消息生成” and choose a model.
3. Use GitKraken's stash message generation feature. To change its model, choose a different model in Magpie.
