# GitKraken Commit Composer

[中文](README.md)

## Purpose

Choose a model specifically for GitKraken's commit composer feature. This plugin updates only the model for commit composing; it does not configure the gateway connection.

## Usage

1. Enable “GitKraken 提交消息生成（Magpie 网关）” first and complete the GitKraken Magpie gateway connection.
2. On Magpie's Agents page, enable “GitKraken 提交编写器” and choose a model.
3. Use GitKraken's commit composer feature. To change its model, choose a different model in Magpie.
