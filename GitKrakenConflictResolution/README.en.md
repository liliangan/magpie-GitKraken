# GitKraken Conflict Resolution

[中文](README.md)

## Purpose

Choose a model specifically for GitKraken's conflict resolution feature. This plugin updates only the model for conflict resolution; it does not configure the gateway connection.

## Usage

1. Enable “GitKraken 提交消息生成（Magpie 网关）” first and complete the GitKraken Magpie gateway connection.
2. On Magpie's Agents page, enable “GitKraken 冲突解决” and choose a model.
3. Use GitKraken's conflict resolution feature. To change its model, choose a different model in Magpie.
